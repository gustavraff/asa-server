Joining from PS5 and using admin

Find the server

  1. Wait until the manager says ONLINE.
  2. Open ASA on PS5 → Join Game → Unofficial.
  3. Enable the player-server and modded-server filters if shown.
  4. Search for Gustavs ASA Server, refresh, and join.
  5. PS5 downloads required cross-platform mods automatically. Let every download finish.

Permanent admin

Your verified 32-character ASA EOS account ID is stored locally in ASA's native ShooterGame/Saved/AllowedCheaterAccountIDs.txt whitelist. The guide deliberately does not print the ID. If automatic admin is unavailable, enter enablecheats <admin password> once after joining.

  2. Open the console from the pause menu.
  3. Enter cheat fly. Use cheat walk to land.
ShowMyAdminManager is not a reliable PS5 test. Flying without first entering the password is the clear permanent-admin test.

If permanent admin ever fails, use the manager's PS5 admin + performance help → Copy admin login. Never share that copied password command with another player.

FPS controls

The B+ Menu mod provides the in-game FPS toggle. Your maximum preset disables clouds, fog, Lumen indirect light/reflections, grass, water reflections, and shadows. It raised the tested PS5 result from about 24 FPS to above 60 FPS. Use the reset option when you want normal visuals.

Change rates safely

  1. Open Guided rates.
  2. Choose a preset or adjust values.
  3. Press Save rates.
  4. Restart when everyone is out.
  5. Test one harvest, tame, and breeding cycle before increasing values again.

Multiplier rule: larger XP/harvest/taming/maturation values make those actions faster. A smaller mating interval means less waiting. Extreme values can skip breeding interactions or make progression meaningless.

Change map safely

  1. Ask everyone to leave.
  2. Press Safe backup.
  3. Select the map in Easy server settings.
  4. Press Save basic settings, then Restart.
Changing maps does not delete Aberration. Each map keeps its own save folder. Characters/items do not automatically transfer unless cluster transfer is deliberately configured later.

Add or remove a mod

  1. Confirm it is for ARK: Survival Ascended, not Survival Evolved.
  2. Confirm the CurseForge page says Cross-Platform or supports PS5.
  3. Read dependencies, required load order, map limits, and uninstall instructions.
  4. Press Safe backup.
  5. Use Manage mods, enter the numeric Project ID, and save.
  6. Restart and wait for the manager/server log to show every mod as valid.
  7. Join from PS5 and test the changed feature.
Removing structure, stack, cryopod, or creature mods can destroy converted items or structures. Read the mod author's uninstall instructions and keep the pre-change backup.

Add large mods in small batches. When something breaks, the most recently added mod is the first suspect.

Saves, backups, updates, and daily maintenance

Automatic protection

  • ASA autosaves every 15 minutes.
  • ASA keeps recovery data including .arkrbf files.
  • Windows Scheduled Task Gustav ASA Daily Maintenance runs daily at 04:00.
  • Connected players receive large restart broadcasts at 60, 30, and 10 seconds before any manager restart, update, backup restart, or daily maintenance. If nobody is connected, the delay is skipped.
  • Maintenance safely stops, verifies a backup, updates App 2430930, keeps the newest 14 daily backups, restarts, validates mods, and wipes wild dinos once.
  • The wild-dino wipe happens only on the daily maintenance restart. Manual starts/restarts do not wipe them.
  • If ASA was already stopped, maintenance backs it up but does not unexpectedly start it.

Before shutting down Windows

  1. Ask players to leave.
  2. Press Safe stop.
  3. Wait until the manager says OFFLINE.
  4. Then shut down or restart Windows.

Restore a backup

Restoring replaces current progress. Keep the current save as another backup first.
  1. Safe stop ASA.
  2. Open backups from the manager.
  3. Choose a dated backup that contains Aberration_WP.ark.
  4. Copy the current SavedArks\Aberration_WP folder somewhere safe.
  5. Restore the selected map folder and restart.

If you are unsure, stop after step 3 and get help. Never delete backups to “make the server see them.”

Troubleshooting

Server does not appear on PS5
  1. Confirm manager says ONLINE.
  2. Wait two minutes and refresh Unofficial servers.
  3. Search the exact name and allow modded/player-hosted servers.
  4. Run the offline advisor.
  5. Open server logs and confirm “now advertising for join.”
  6. Do not repeatedly change router rules while the server is known to have worked.
Connection timeout

Confirm Windows still uses 192.168.1.179, VPN software is not taking over the server route, UDP forwarding still targets this PC, and ASA is listening on 7777/27015. Restart ASA once after checking—not repeatedly.

Version or mod mismatch

Ask players to leave and use Update + restart. Let the server validate every mod. On PS5, allow all mod updates to finish before joining.

Admin command does nothing

Wait 30 seconds after joining and try cheat fly. If it fails, use Copy admin login, enter that once, then retry. Check that the exact EOS ID remains in Manage permanent admins.

Server or Windows crashes

Restart Windows, open the manager, run the offline advisor, then start ASA. The 15-minute autosave and recovery files should limit rollback. If the world will not load, stop and restore the newest verified daily backup.

High RAM usage

Aberration plus nine mods can use substantial RAM. Do not run the full Steam ASA client on this 16 GB server PC at the same time. Use PS5 as the player client.

Daily maintenance result

Read DailyMaintenance-last-result.txt for the short result and DailyMaintenance.log for details. A result of 0 in Task Scheduler means success.
